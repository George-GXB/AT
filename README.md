# テスト対策 一問一答

教科書・ノート・スライドを撮った画像を取り込むと、その内容から **4択の一問一答**を自動生成し、
回答した瞬間に答え合わせと正解表示を行う学習アプリです。iPhone での利用を前提とした PWA です。

- **追加費用ゼロ** — 外部の AI API を一切使わず、文字認識も問題生成もすべて端末内で完結します
- **画像は残さない** — 取り込んだ画像はメモリ上だけで処理し、文字に変換した時点で破棄します
- **端末内保存** — 問題集は IndexedDB に保存し、合計 1GB を上限として管理します
- **オフライン動作** — 一度開けば機内モードでも出題できます

## セットアップ

```bash
npm install
npm run setup:ocr   # OCR のエンジンと日本語/英語の学習データを public/ に用意する(初回のみ・約26MB)
npm run dev         # http://localhost:5173
```

`npm run setup:ocr` は tesseract.js の wasm を `node_modules` からコピーし、学習済みデータを
ダウンロードして `public/` に置きます。以降アプリが外部へ通信することはありません。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド(`dist/`) |
| `npm test` | 問題生成ルールと保存層のテスト |
| `npm run setup:ocr` | OCR アセットの準備 |
| `npm run icons` | アイコンの再生成 |
| `npm run shots` | iPhone 17 のサイズで全画面のスクリーンショットを撮る(要 `npm run dev`) |

`npm run shots` はインストール済みの Chrome / Edge をヘッドレスで起動し、CDP 経由で
402×874 の画面を撮影します。`OCR=1 npm run shots` にすると OCR 経路も通します。

## iPhone で使う

Service Worker とホーム画面へのインストールには **HTTPS が必須**のため、
`http://<LAN内のIP>:5173` では PWA として動作しません。無料の静的ホスティングに置いてください。

```bash
npm run build          # dist/ を生成
# dist/ を Cloudflare Pages や GitHub Pages に配置する
```

GitHub Pages のプロジェクトサイト（`https://<user>.github.io/<repo>/`）に置く場合は、
ビルド時にパスを指定します。

```bash
BASE_PATH=/<repo>/ npm run build
```

公開した URL を Safari で開き、共有ボタンから **「ホーム画面に追加」** を選ぶと、
アドレスバーのないアプリとして起動します。

## 問題の作られ方

外部 AI を使わないため、文章の形からルールで問題を組み立てます。

| ルール | 拾う形 | 例 |
| --- | --- | --- |
| 用語・定義 | `〇〇とは…である` / `〇〇：…` | 説明文を問題にして用語を答えさせる |
| 英単語 | 同じ行に英単語と訳 | 英→日 と 日→英 の両方向 |
| 年号・数値 | `1467年` など | その数値を空欄にする |
| 穴埋め | 上記以外の文 | 文中の重要語を空欄にする |

**誤答の3つは、同じ資料の中にある他の語から選びます。**同じ分野の語が並ぶので、AI を使わなくても
自然に紛らわしい選択肢になります。誤答を3つ用意できない問題は、不自然な4択になるため生成しません。

ルールベースである以上、外れた問題も混ざります。そのため生成直後に**確認・編集画面**を挟み、
採用・削除・文言の修正ができるようにしています。

## 画像を残さない仕組み

- 画像は `File` → `ImageBitmap` → `ImageData` とメモリ上だけで受け渡します
- OCR が終わると `ImageBitmap` を閉じ、canvas を 0×0 にしてメモリを解放します
- `<input type="file">` の値は読み取った直後に空にします
- **保存層(Dexie)に画像用のテーブルを定義していません** — 構造的に保存できません

## 構成

```
src/
  routes/     Home / Import / Review / Quiz / Result / Settings
  generator/  問題生成(normalize・distractors・rules/*)
  ocr/        画像の前処理と Tesseract.js の呼び出し
  db/         Dexie スキーマ・1GB 管理・バックアップ
  ui/         画面共通の部品
scripts/      OCR アセット準備・アイコン生成・スクリーンショット
```

## 注意点

- iOS はしばらく使っていないサイトのデータを消すことがあります。大切な問題集は
  設定画面から**バックアップを書き出して**ください。
- 縦書きや手書きの文字は OCR の精度が落ちます。その場合は写真アプリで文字を長押しコピーし
  （iPhone 標準の文字認識）、取り込み画面のテキスト欄に貼り付けてください。
- iOS Safari は `navigator.vibrate` に対応していないため、触覚フィードバックはありません。
  正誤は色・記号・アニメーションで示します。
