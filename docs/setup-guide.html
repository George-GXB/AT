「一問一答」をiPhoneに入れる

追加費用なし・ダウンロード不要。Safariでページを開いて「ホーム画面に追加」するだけで、 アプリのように使えるようになります。所要時間はだいたい5分です。

📦 github.com/George-GXB/AT 🔗 公開URL: george-gxb.github.io/AT/
はじめに このアプリは GitHub Pages という無料の仕組みでそのまま公開されます。サーバー費用も アプリ内課金もありません。ただし iPhone にアイコンとして追加できるのは Safari から開いた場合だけです。Chrome など他のブラウザでは 「ホーム画面に追加」がうまく機能しないので、必ず Safari を使ってください。

1GitHub Pages を有効にする（最初の1回だけ）

リポジトリの設定画面を開き、公開の仕組みを「GitHub Actions」に切り替えます。 この操作は最初の1回だけで、以降は不要です。

  1. github.com/George-GXB/AT/settings/pages を開く
  2. 「Build and deployment」の「Source」を GitHub Actions に変更する
github.com/George-GXB/AT/settings/pages
Source GitHub Actions

2公開が終わるのを待つ

設定を保存すると、自動でビルドと公開が始まります。1〜3分ほどで完了します。 進み具合は Actions タブで確認できます。

  1. github.com/George-GXB/AT/actions を開く
  2. 一番上の実行に緑色のチェック ✓ が付けば公開完了
github.com/George-GXB/AT/actions
✓ Deploy to GitHub Pages 2分前
✓ Deploy to GitHub Pages 昨日
赤い × が出たら 実行名をクリックしてログを開き、どの手順で失敗したか確認してください。多くの場合は 一時的なネットワークエラーなので、Actions タブの「Re-run all jobs」で再実行すれば直ります。

3iPhoneのSafariで開く

iPhoneの Safari を起動し、アドレス欄に次のURLを入力します。

george-gxb.github.io/AT/

🔒 george-gxb.github.io/AT/

5動作を確認する

追加したアイコンをタップして起動し、次の2点を確認してください。

  • アドレスバーのない、アプリらしい画面で開くこと
  • 一度開いたあと機内モードにしてもう一度アイコンから起動し、 そのまま操作できること（オフラインでも動く設計です）
初回だけ注意 画像から問題を作る機能を初めて使うとき、文字認識用のデータ（約26MB）を 端末にダウンロードします。ここだけは通信が必要なので、初回は Wi-Fi環境で行うことをおすすめします。ダウンロード後は次回から通信不要です。

うまくいかないとき

「ホーム画面に追加」の項目が出てこない

Safari以外のブラウザ（Chrome・LINEアプリ内ブラウザなど）で開いている可能性があります。 共有ボタンを押す前に、画面上部が Safari のアドレスバーになっているか確認してください。

ホーム画面のアイコンが真っ白、または開けない

Actions タブで最新の実行が緑チェックになっているか確認してください。まだビルド中か失敗している場合、 ページが正しく公開されていません。一度アイコンを削除し、公開完了後にやり直してください。

アプリを更新したのに古いまま表示される

オフラインでも使えるようにする仕組み（Service Worker）が、裏側で新しいバージョンを 用意してから切り替えます。アプリを一度完全に終了して開き直すと最新版になります。 それでも変わらない場合は、ホーム画面のアイコンを一度削除して追加し直してください。

今後アプリを更新したら、また同じ手順が必要？

いいえ。master ブランチに変更を push するたびに、GitHub Actions が自動で ビルドして同じURLに再公開します。STEP1（Pages の有効化）は最初の1回だけで、 以降はホーム画面のアイコンを開き直すだけで最新の内容になります。

このドキュメントはリポジトリ docs/setup-guide.html にあります。 アプリ本体の仕組みについては README.md を参照してください。
